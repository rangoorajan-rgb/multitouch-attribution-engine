# Data Model

## customer_journey

Stores every marketing interaction a customer has before becoming a customer.

Examples:

- Google Ads
- LinkedIn Ads
- Organic Search
- Email Marketing
- Direct

---

### Columns

- touch_id
- customer_id
- touch_date
- marketing_channel
- campaign_name
- touch_position

## deals

Stores CRM opportunity information.

Examples:

- Customer ID
- Deal Stage
- Deal Value
- Close Date

---

## attribution_results

Stores calculated attribution outputs.

Examples:

- First Touch
- Last Touch
- Linear
- Time Decay
